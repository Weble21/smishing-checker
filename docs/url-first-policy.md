# URL 우선 최종 판정

2026-09-15 사용자 지정 정책. 기존 문자 모델과 URL 모델을 유지하며 risk.py가 최종 등급을 결정합니다.

| 조건(위에서부터 우선 적용) | 등급 |
|---|---|
| URL 결과에 DANGEROUS가 하나라도 있음 | HIGH / 위험 |
| 공식 여부 미확인 URL + 직접·간접 접속 유도 | HIGH / 위험 |
| 공식 여부 미확인 URL, 접속 유도 없음 | MEDIUM / 주의 |
| 모든 URL이 화이트리스트 공식 도메인이고 언급 기관과 일치(기관 언급 없으면 등록 여부) | LOW / URL 기준 안전 |
| URL 없음 | LOW / URL 기준 안전 |

SUSPICIOUS는 악성 확정이 아니라 의심 상태입니다. 화이트리스트로 확인되지 않으면 미확인으로 취급합니다.
NO_KNOWN_THREAT는 악성 신고 이력이 없다는 의미이며 단독으로 안전 판정하지 않습니다.
INVALID, 평판 조회 실패, 누락된 URL 분석 결과는 미확인입니다.
메신저 링크는 상대방 신원을 보증하지 않아 미확인으로 처리합니다.
문자 모델 점수는 이 규칙을 단독으로 뒤집지 않습니다. /analyze는 LLM 문맥 리뷰를 호출하지 않습니다.

인증 미완료 시 서비스 중단, 서류 미제출 시 취소 같은 불이익과 링크가 함께 있으면 간접 유도로 탐지합니다.
기존 앱을 직접 실행하도록 안내하는 표현과 링크 클릭 금지 표현은 접속 유도에서 제외합니다.
접속 유도 탐지는 규칙 기반이므로 모든 표현을 이해한다고 보장할 수는 없습니다.
URL 없음은 URL 기준의 분류이며 송금·가족 사칭 등 링크 없는 사기를 배제한다는 뜻은 아닙니다.

## 격리 환경에서 URL 확인

먼저 urlscan.io에서 기존 검사 결과를 검색하면 직접 접속 없이 기록을 확인할 수 있습니다.
새 스캔은 원격 브라우저가 URL을 방문하며 해당 주소가 외부 서비스에 전달됩니다.
Public은 공개이고 Unlisted도 일부 보안 연구자·업체에 보이므로 비공개와 같지 않습니다.
개인별 인증 토큰이 포함된 링크는 공개 스캔에 제출하지 마세요.
출처: https://docs.urlscan.io/pages/visibility

직접 조작하려면 Windows Sandbox를 활성화한 PC에서 docs/url-inspection.wsb를 실행하고,
격리된 브라우저 주소창에 URL을 입력하세요. 클립보드·폴더 공유 없이 네트워크만 허용하는 설정입니다.
실제 계정으로 로그인하거나 인증정보를 입력하지 마세요. 끝나면 Sandbox를 종료합니다.
네트워크 활성화는 내부망 접근까지 차단하는 설정은 아닙니다. 민감한 내부망에서는
인터넷 전용으로 네트워크를 분리한 가상 머신이나 원격 분석 환경을 사용해야 합니다.
출처: https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-configure-using-wsb-file

이 작업에서는 의심 URL 접속, 원격 스캔 제출, Sandbox 실행을 수행하지 않았습니다.
