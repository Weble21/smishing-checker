# 동적 URL 분석 1차 범위

## 분석 대상

정적 URL 분석 결과가 `UNKNOWN` 또는 `SUSPICIOUS`인 HTTP(S) URL과 최종 목적지를
확인할 수 없는 단축 URL을 대상으로 한다. 공식 도메인으로 확인된 URL과 이미
`DANGEROUS`로 판정된 URL은 자동 방문 대상에서 제외한다. 한 문자에서 분석할
URL 개수와 동일 URL 재분석 주기는 작업 큐 단계에서 제한한다.

## 수집 증거

브라우저는 페이지를 연 뒤 다음 정보만 관찰한다.

| 증거 | 제한 |
|---|---|
| 최종 URL과 주 문서 이동 응답 | URL 쿼리 값과 fragment 제거 |
| 제목과 화면 표시 문구 | 문구 최대 10,000자 |
| 폼 action, method, 입력 유형 | 폼 최대 30개, 값 입력 없음 |
| 네트워크 요청 URL, method, resource type | 최대 100개, 쿼리 값 제거 |
| 다운로드 시도 파일명 | 다운로드 저장 및 실행 없음 |
| 화면 캡처 | 1280×720 현재 화면 1장 |

브라우저는 클릭, 문자 입력, 로그인, 폼 제출, 권한 승인, 파일 실행을 하지 않는다.
각 요청은 새 Chromium 프로세스와 새 브라우저 컨텍스트를 사용하고 종료 시 폐기한다.

## 결과 의미

`COMPLETED`는 증거 수집이 끝났다는 뜻이며 안전 판정이 아니다. `TIMED_OUT`과
`FAILED`는 판단 불가 상태로 처리한다. 동적 분석 증거를 최종 위험도나 확률에
반영하는 규칙은 별도로 검증한 뒤 추가한다.

## 현재 활성화 조건

워커는 외부 통신이 없는 Docker 내부 네트워크에서 실행된다. 별도 프록시만 내부
네트워크와 외부 네트워크에 함께 연결되며 각 요청의 모든 A/AAAA 결과를 검사하고
검사한 공개 IP에 직접 연결한다. 리다이렉트와 하위 리소스 요청도 각각 검사한다.
Compose는 프록시가 준비됐을 때 `DYNAMIC_ANALYSIS_EGRESS_READY=true`를 설정한다.
`DYNAMIC_ANALYSIS_ENABLED`는 기본적으로 `false`이며 배포 환경에서 직접 연결
차단과 프록시 동작을 확인한 뒤 활성화한다.
